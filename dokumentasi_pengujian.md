# Dokumentasi Pengujian Sistem ITK-Mart

1. Login gagal jika username atau password salah.
2. Transaksi gagal jika uang tunai pembeli tidak mencukupi.
3. Transaksi gagal jika stok barang tidak mencukupi.
4. Transaksi sukses jika seluruh syarat terpenuhi.
5. Setelah transaksi sukses, stok berkurang dan poin member bertambah 10.
